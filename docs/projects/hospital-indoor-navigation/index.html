Hospital Indoor Navigation

Solo — design, development, data processing, testing

Prototype web app for navigating a multi-floor general hospital: 3D map, A* multi-floor routing, BLE beacon positioning, step-by-step voice guidance, and wheelchair path mode.

Stack

JavaScript (ES modules) Three.js 0.186 Vite 5 HTML/CSS Python 3 Web Bluetooth WebSocket Node.js

Highlights

  • Render a three-floor 3D map (Three.js) with floor switching, rotate/zoom, and room color-coding by type
  • Implement A* multi-floor routing with elevator/stair transitions; wheelchair mode excludes stairs from the path
  • Bridge BLE beacon signals via Python (bleak) + WebSocket relay with pairing code to operate outside secure context on LAN
  • Fall back to 2D SVG map when WebGL is unavailable (?force2d=1); include kiosk mode with enlarged text and touch targets
  • Build admin panel for technicians to view active beacons, assign positions on the 3D map, and record RSSI calibration data
  • Build Python pipeline (OpenCV, trimesh) converting floor-plan images to 3D GLB models
  • Deliver step-by-step voice guidance with off-route detection and signal-loss alerts
