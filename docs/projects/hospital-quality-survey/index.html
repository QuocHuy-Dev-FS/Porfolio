Hospital Quality Survey

Fullstack Developer

Next.js 16.4 React 19.3 TypeScript Tailwind CSS 4 Supabase PostgreSQL Supabase Auth Recharts 3 Lucide React ESLint 9 Node.js

Overview

Patient satisfaction kiosk and quality management portal built for a Grade-I hospital. Survey flow covers department selection, criteria rating, and NPS; admin dashboard tracks KPIs, charts, and complaints.

Highlights

  • Resolve department-code mismatches with a multi-step resolveDepartment function (exact → prefix → name → static map); verify correctness with a custom test script without altering DB data
  • Enforce two-layer security at server and DB level, not only in UI; apply migration for secure feedback table and status-history tracking
  • Design for public kiosk use: large touch targets, custom TouchNumpad, KioskIdleTimer auto-reset, and countdown screen after submission
  • Configure survey forms in the database; maintain surveyFallback so the kiosk works when the API is unavailable
  • Write idempotent SQL migrations; export complaint data as CSV with UTF-8 BOM for correct Vietnamese character display in Excel
