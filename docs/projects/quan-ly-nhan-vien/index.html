Employee Management

Full-stack (sole developer)

Next.js 16 React TypeScript Tailwind CSS Supabase PostgreSQL Vitest Framer Motion React Hook Form Zod date-fns ESLint

Overview

Web app replacing paper shift rosters and Excel payroll sheets for small F&B outlets. Handles shift registration, weekly scheduling, and hourly pay calculation.

Highlights

  • Enforce multi-layer security: route proxy + server-side layout guard (requireAuth/requireAdmin) + RLS on Postgres; migrate policies from anon to authenticated; verify anon INSERT returns 401 and anon SELECT returns empty array
  • Implement role-based access via app_metadata.role; run role-change API server-side with Service Role Key only
  • Version the database with SQL migrations covering salary/schedule expansion, account linking, shift registration, notifications, and payroll confirmation
  • Cover business logic with unit tests: shift-hour calculation by role, monthly totals, money formatting, and registration-to-approval-to-payroll flow
  • Apply CSS token design system; maintain text contrast at WCAG AA level; set touch targets to minimum 44px; support responsive layouts at 375/768/1024/1440px with no horizontal scroll
